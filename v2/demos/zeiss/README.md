# 质量知识问答与数据查询演示

这是基于 Owen 简历中蔡司镜片 SAP 升级项目场景自建的静态演示原型，所有业务数据、身份、文档内容与责任岗均为虚构示例，不代表客户内部系统或实际业务效果。

## 打开方式

双击 `index.html`，用浏览器打开。将本目录的 `index.html`、`style.css`、`app.js` 保持在一起。无需服务器、构建、安装依赖或联网。也可在项目根目录用浏览器打开 `out/index.html`。

点击顶部“演示模式 / 自动播放”，从讲稿第一帧开始，每帧停留 8 秒，完整播放约 2 分钟。再次点击暂停，点击“继续播放”从当前画面继续（重新计满 8 秒）；播放结束自动停下，可重新播放。切到其他窗口或标签页时自动暂停，不会自行恢复。

键盘 `←` / `→` 切换当前流程步骤；播放期间按方向键会暂停，并沿讲稿逐帧切换。在评测页自由浏览时，方向键切换评测题。在顶部页面标签获得焦点时，方向键切换页面。下拉选择器内保留原生方向键操作。点击场景、步骤、页面标签或回归按钮会暂停并退出讲稿路线，再次自动播放将从头开始。手机端通过下拉框选择六个场景。

可将这三个文件放入个人网站 `demos/<name>/` 目录。左上角“← 返回作品集”固定指向 `../../index.html`；单独打开无需父级首页即可使用演示，也不会探测或请求父级文件。返回链接仅在点击时按相对路径导航。系统启用“减少动态效果”时禁用入场动画与平滑滚动，自动播放仍需手动启动。

## 页面结构

- 顶部常驻“演示用示例数据”标识，滚动时仍然可见。
- “问答流程演示”：左侧六个场景，右侧六步流程。点击上一步、下一步或步骤条可查看每一步的输入、系统处理、输出与产品设计要点。末步可重新演示。
- 六个场景：规则问答、未决策检验批、不合格批次查询、缺参澄清、越权拦截、仅有废止依据的拒答。澄清示例在分类步骤出现补充按钮，点击后回到权限校验步骤。
- “评测与问题归因”：五道示例题分别展示理解、检索、生成、工具、权限与数据层主因。第一题可点击“应用修复并运行本地回归”，重现新旧两版同时召回到仅召回现行版本的变化。其他题为归因说明。
- Dify 节点标注是方案映射。页面未连接 Dify、SAP、真实身份系统或语言模型；分类用关键词，回答用模板，受控接口用本地函数模拟。固定身份仅用于演示权限边界，不是安全认证实现。

## 数据与事实边界

事实来源是 `../ref/resume_v1_final.md` 的蔡司项目；流程参考 `../ref/PLAN.md`。嵌入的检验批来自 `../ref/data/business_status.csv`，规则时限和版本来自教学作业指导书。原始资料未修改。

文档现行/废止状态按新版替代旧版规则整理。责任岗和元数据治理条件是演示配置。额外的“旧包装复检作业指导书”是专为仅有废止依据场景补充的虚构用例，不是原始文档或客户资料。五道评测题是演示设计，不能说成实际专家已标注的评测结果。

数据分支按工厂、创建月份筛选，排除取消批。未决策指使用决策为空；不合格批次指已决策且不合格数量大于零的批次，不计算不合格率。时间展示为所选范围内最近更新时间，属于离线快照，不是实时查询时间。所有结果数量明确标注示例值。检验规则中的小时数是教学规则，不是耗时缩短等效果指标。

未展示真实准确率、用户数、查询量或改善幅度，也未填入简历中尚待补齐的数值。

## 面试可能追问 & 回答要点

1. **你具体负责什么？** 简历描述的角色是系统切换项目经理助理、质量流程与数据治理顾问；涉及切换计划与演练支持、质量流程梳理、知识治理、问答和查询方案、评测与推广。不要把团队全部工作说成个人独立完成。
2. **为什么不能所有问题都走知识库？** 规则和定义来自文档，状态与统计来自业务数据；简历明确要求数据查询走受控接口、返回数据时间和口径，不让模型估算数字。
3. **为什么只加强提示词不够？** 简历中的错误主因是新旧文档同时召回，修复是在知识治理和检索层补齐版本、状态并硬过滤现行状态，回答再附来源与版本。
4. **如何证明修复有效？** 简历方法是固定问题、知识版本与评分标准，分开调试集和验证集，逐层归因、单变量回归。实际题量、准确率和改善幅度未提供，不能用本页结果替代。
5. **权限、缺参和无依据怎么处理？** 简历要求查询前校验身份与数据访问范围，信息不全先澄清；没有有效依据或只命中废止版本则拒答并给出责任人。页面用固定身份和责任岗演示这条链路。
