02.2 / 关键决策 · 为什么选 A 不选 B
DECISION · RAG + Skill vs 微调
背景案例只有十余个，专家规则每周都在改。
候选微调专用模型 / RAG + Skill。
选择先用 RAG + Skill；案例过百且同类纠偏反复出现再评估微调。
结果依据全程可追溯，规则修改当天生效。
DECISION · Skill 渐进式披露 vs 长提示词
背景所有规则塞进一个提示词，注意力被稀释，触发也不稳定。
候选单一长提示词 / 多 Agent / Skill。
选择封装成 Skill，description 带正反例，references 按需加载。
结果Skill 触发 11/12。
DECISION · 整案例召回 vs 片段召回
背景片段召回会丢掉适用条件。
候选固定切片 / 父子分段。
选择子块命中，父块整案例召回，带适用条件。
结果召回内容总带适用条件。
DECISION · 存与变两维 vs 只看字段
背景字段存在被误判为原生支持。
候选只查字段 / 存与变两维。
选择追问谁触发、什么机制，两维都支持才判原生。
结果调价类误判修复。
DECISION · 逐项追问 vs 一次性长表单
背景顾问不愿填长表单，模型又会默认补齐。
候选长表单 / 不追问直接生成 / 逐项追问。
选择一次一项最多 3 轮，仍缺转假设。
结果缺失信息全部显式进入假设块。
DECISION · 要点判分 + 顾问复核 vs 纯人工
背景逐份人工评审太慢。
候选纯人工 / 纯模型 / 混合。
选择顾问标关键要点，LLM 初判，顾问复核。
结果评分 0.6 → 1.7，每次改动可快速回归。
